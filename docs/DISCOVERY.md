# B 站公开视频发现

先在主人或 AstrBot 管理员的私聊中添加订阅：

```
/bili 订阅 关键词 崩铁 新剧情
/bili 订阅 UP 123456
/bili 订阅
/bili 发现
/bili 退订 1
```

订阅和已经发现的 BV 号保存在 B 站插件数据目录的 `discovery.db`。重复订阅复用原编号；视频在多个来源出现时合并来源，同一个 BV 号只形成一次新候选，重启后仍然去重。退订保留已经发现的视频记录。

“发现”依次调用 bili-agent 的 `search video <词> --order new --size 5` 和 `user videos <UID> --order new --size 5`，读取每个来源最新五条公开视频。随后按可获得的播放量降序展示候选，播放量只是热度参考，不代表内容质量或推荐结论。结果包含标题、BV 号、UP、发布时间、来源和视频链接。

新候选同时写入共享记忆的 `public/video` 层，不读取私人记忆。来源错误会逐条显示；成功来源仍可产出候选，失败来源不更新去重记录。若无法保存公开记忆，该候选不会标为已发现，修复记忆库后可重试。

本版仅由 `/bili 发现` 手动触发，没有增加后台订阅轮询，不改变现有收件箱轮询或自动回复配置。它不生成文案、不投稿、不评论、不发私信；选题及后续制作由现有创作流程处理。
