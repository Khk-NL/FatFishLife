# 微信入站图片和语音附带转写

日常 DSH 的 `dsh-wechat` 适配包 `8f10631e0f63` 支持已绑定主人私聊单条消息的第一张 JPEG 或 PNG。沿用 iLink 官方 CDN 和 DSH 原生图片附件，单张最多 4 MiB。下载临时文件在提交给 DSH 附件服务后清理。回复仍为文字，微信会话的后台工具和主动发送保持关闭。

语音使用微信消息已经附带的转写。无转写、无法读取的图片、视频或普通文件会收到相应提示。独立语音识别与媒体发送还未接入。重新部署可使用 `scripts/prepare_wechat_shared_context.py` 生成固定上游的适配归档。

隔离验证通过图片附件构造、非图片拒绝、临时下载清理和原有微信回复门禁。日常通过自带管理器换包，配置摘要一致。真实微信图片和语音尚未验收。
