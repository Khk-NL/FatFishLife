# 微信主人私聊能力

微信通过现有 iLink 适配收消息。仅已绑定的本人私聊进入这套工具，回复使用原会话的 `context_token`。微信入口和原 FatFish MCP 都验证授权。模型只收到当前回合允许的工具，真实会话、原文和短期签名由宿主提供。

| 想做的事 | 当前行为 |
| --- | --- |
| 查资料与回忆 | 查本地公开知识库，或查本账号、当前私聊的前三条匹配笔记。 |
| 记住内容 | 本条直接说“请记住……”可立即保存。同一条消息不能覆盖原文。其他明确的偏好或称呼先放入待整理队列，北京时间 23:30 批量转入长期记忆。关机错过时在下次宿主启动补齐。引用、附件、疑似凭据和越权指令不进入记忆。 |
| 查或打开应用 | 自行查看 Outlook、AUTO-MAS、学习通状态。明确说“帮我打开经典 Outlook”等时启动对应的 Windows 注册应用。启动回执表示已请求打开，运行状态可另查。 |
| 表情包和图片 | 使用既有图库。明确索要可直接选图，普通回复有合适情绪时按 55% 尝试。每条已确认的文字回复最多附一张，避免连续发同一张。只发经过图库与格式校验的图片，上传失败不重传。 |
| 找今天的 DSH 插件视频，整理到桌面 | 按北京时间筛选当天公开搜索结果，按已知播放量排序，最多十条。通过已装的 Video Storyboard 读取首集画面，合并已有字幕摘录，用一次视觉请求生成画面要点。正文附可跳转到对应取帧位置的时间链接。首集超过五分钟或画面分析失败的条目会标明核验未完成，回执列出实际分析数量。QQ 发送受阻时仍可保存文档。 |
| 总结今天邮件 | 复用经典 Outlook 已登录、已打开的默认收件箱。每次最多十封，仅把主题、时间和短摘录交给当前微信回合做摘要，邮件正文不写入任务回执或长期记忆。未打开或不可读时明确返回状态。 |
| 在 B 站发随想视频 | 鲸鲸用本轮模型请求写一段可公开的想法和三个镜头动作，保存为本地 Updream 分镜和待审回执。预算、素材与成片仍需确认后才可制作、上传和投稿。 |

每轮最多两步模型请求，第一步最多两次查询和一次写入、打开或工作流执行。第二步汇报结果。工具失败、拒绝、额度不足或结果未知不补试。每日最多新增十二条记忆、接收四项桌面工作流。记忆与任务回执都按微信账号与私聊分区，延续 `/new` 后的同一主人记忆。

显式 B 站报告在聊天两步之外使用至多一次视觉请求，每条一张低清六格分镜。读取已有字幕与取画面分开处理。计划任务沿用北京时间工作日 09:00–12:00、14:00–18:00 的峰时规则和现有调休表，日常聊天与明确下达的主人私聊任务按现有授权处理。峰时不领取后台运营或峰时整理任务。

## 平台接口

- 微信使用官方 iLink Bot 会话绑定、上下文令牌以及官方媒体上传和回复形态。图库图片先取上传参数，再加密上传，最后带同一私聊的令牌发送图片项。 [腾讯 iLink 协议说明](https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol_zh_CN.md)
- QQ 计划使用腾讯官方 Bot API，其账号与可发送范围独立授权。QQ 还未接入，本能力不抬升 QQ 权限。 [QQ Bot 开发文档](https://bot.q.qq.com/wiki/)
- B 站视频检索复用已装的只读 bili CLI。该客户端与开放平台授权是两条不同的接口路径。投稿、以账号名义发送等写操作按开放平台授权和审核要求单独验收。 [哔哩哔哩开放平台](https://openhome.bilibili.com/doc) · [运营规范](https://openhome.bilibili.com/agreement/management-protocol)
- 邮件使用微软经典 Outlook 对象模型访问已登录的默认收件箱。不安装邮件代理，不读取登录凭据。 [Outlook Items 接口](https://learn.microsoft.com/en-us/office/vba/api/outlook.items)

本轮继续复用 MIT 的 dsh-wechat 固定包、DSH 原生工具执行和已有 FatFish MCP、SQLite、图库、bili CLI、Updream。完整第三方使用约定见 [MCP 接入规范](MCP_INTEGRATION.md)。

## 启用与撤回

配置由运行 FatFish 的 Windows 所有者控制。微信与 MCP 共用 `FATFISH_DSH_DATA` 目录里的私有授权文件。将该目录中的 `wechat-capability.key` 通过本地操作改名为 `wechat-capability.disabled` 可立即关闭新增能力，原聊天、笔记和待整理队列保留。恢复原名后，新微信会话会重新检查授权。

2026-11-20 隔离验收通过真实 MCP、SQLite、模型请求的权限层和模拟 iLink 图片链。真实 B 站只读搜索返回 50 条候选，其中 5 条可确认当天发布，结果不足十条时按实际数量输出。未读取真实邮件、付费、上传或发送测试微信及 QQ 消息。
