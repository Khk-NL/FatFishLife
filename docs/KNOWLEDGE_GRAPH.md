# 有来源的知识图谱

公开设定采用实体和关系检索，原文索引保留为核对证据。数据和原有成长记录共用本机 SQLite，部署无需新服务。

图谱区分人物、组织、地点、事件、物品、概念。每条关系都有原文片段、文档和来源链接；模型给不出真实依据时不入库，不以它的记忆补齐资料。

## 在 QQ 中查看

- `/设定 图谱`：公开资料、实体、关系数量。
- `/设定 能天使的姐姐是谁`：优先给图谱关系及出处，再补充原文检索。
- 老板私聊 `/设定 导入`：同步更新过的资料并增量构图。失败文档保留原版本，成功更新替换旧关系，已删除文档移除派生索引。
- 老板私聊 `/知识库 搜索 <问题>`：检索私人 Obsidian 图谱及笔记。私人图谱不会进入群聊、B站或公开检索。

普通对话会自动参考相关公开关系。模型也可调用 `knowledge_graph_search` 与 `prts_story_lookup`，按真实章节核对剧情。活动公告不能作为剧情细节的证据。

## 维护

`scripts/build_knowledge_graph.py --astrbot <AstrBot目录>` 构建公开图谱；加 `--private-vault <目录>` 才处理私人笔记。报告只含计数、错误类别；私人文件名使用摘要标识。默认只请求变更文档。

`scripts/build_activity_knowledge.py --astrbot <目录>` 从 PRTS 情报处理室的游戏内回顾整理事实提要，保存真实剧情章节索引。旧的活动生成入口统一转到此流程。

## 群聊表达成长

`/语气 状态` 与 `/语气 样本` 可查看本群吸收的表达习惯、回复引用和反馈。老板可 `/语气 学习`；收到回复的人可 `/语气 喜欢` 或 `/语气 不喜欢`。学习仅取公开群聊中可核对的群友语料，至少两条证据，不把他人的身份和经历当成自己。

## 音色准备

现有 CosyVoice 维持语速 1.1。已备好同角色的普通、活泼、轻柔参考录音和切换逻辑；本轮合成请求超时，保留原来音色，新参考待服务恢复后试听通过再启用。参考切换不等于模型原生情绪控制。

MiniMax 适配沿用已安装的情绪路由插件。可在本机 `.env` 填 `FATFISH_MINIMAX_KEY` 和克隆成功的 `FATFISH_MINIMAX_VOICE_ID`，运行服务配置脚本后准备就绪；脚本保留现有引擎，等试听通过再切换。克隆接口与文件要求见 [MiniMax 官方文档](https://platform.minimax.cn/docs/api-reference/voice-cloning-clone)。
