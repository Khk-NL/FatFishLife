# 微信 ClawBot 接入 FatFishLife

微信 ClawBot 通过腾讯 iLink 接入日常 DSH。微信沿用现有 `whale-social` 人设和已绑定的微信会话。已认证的主人微信私聊还会读取现有成长摘要、B 站日记的最新片段和当天的「看过」记录。视频日期按北京时间计算，夜间跳过以实际事件为准。各平台聊天记录按原会话保存，微信的内容目前也不会反向写入 B 站日记。FatFishLife 的渠道专用额度停止与报告仍待接入微信。

## 绑定步骤

1. 用你平时要和鱼聊天的微信号，打开 **我 → 设置 → 插件 → ClawBot**。需要微信账号已有该入口。绑定用微信客户端扫码，凭据在本机保存。
2. 保存 DSH 工作，从 Windows 托盘完全退出 DSH。双击 `D:/Code/Projects/FatFishLife/scripts/install-dsh-wechat.cmd`。脚本会校验预备包的 SHA256、备份现有桌面配置并通过随包管理器安装。
3. 安装完成后，打开 DSH。进入 **设置 → 微信 → 添加绑定**，用第 1 步的微信号扫描二维码并确认授权。二维码和凭据只在本机使用。如果扫码过期，在同一页面刷新。默认关闭自动扫码、额外允许名单、媒体和后台生命周期通知。
4. 微信里打开 ClawBot 私聊。先发 `/status` 检查连接，这条走插件自身命令。确认后发一句「鲸鲸，在吗？」检查人设和实际一问一答，这条会调用已配置的模型。
5. 卡住时发 `/stop` 结束当前回合。要解除绑定，在 DSH **设置 → 微信** 移除相应绑定。

投入日常使用前，需单独验证微信上的失败停机和报告。上游插件的等待超时只停止微信端等待，模型回合可能继续在后台执行。

## 版本与验收

- 使用 [dsh-wechat 0.3.7 固定源码](https://github.com/zgat/dsh-wechat/tree/8213a830351753f128926b535693355b2f77763e)，MIT。打包保留上游 `LICENSE`。本机包在 `outputs/clawbot-20261114`。另一款 `deepseek-harness-weixin` 0.2.5 隔离安装成功，但在实际 DSH 0.2.2-rc.1 无法加载，涉及旧凭据服务和包解析。
- 一键安装脚本通过实际 DSH 管理器在隔离 desktop profile 安装并读回。插件也在实际 DSH 0.2.2-rc.1 的隔离 Web profile 加载成功，限制配置下未绑定、仅白名单，未自动生成二维码。该次隔离环境的原生临时缓存插件报 `EPERM`，微信插件仍已启动。上游 Windows 副作用检查中，7 项通过，另 1 项因测试按 Unix 路径分隔符查找文件而报错。
- 2026-11-16 已安装日常插件，扫码绑定后已观察到真实微信渠道收发。随后更新了同一插件的微信提示和主人私聊上下文，模拟验证主人才能读取成长和 B 站活动、同一会话继续使用、一条入站只发一次回复。新版本的口吻和 B 站问题仍需在真实微信对话中核对。
