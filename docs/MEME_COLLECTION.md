# 聊天收藏表情

发送 `\表情 收藏`（也支持 `/表情 收藏`），再在 5 分钟内发送一张图片。
只接收同一会话、同一用户接下来发来的第一张图片；文字不会消耗等待状态。
发送 `\表情 取消` 可取消。多人可分别等待收藏，不会互相抢图。

图片等比缩放并补透明边至 300×300，不裁剪或拉伸，动图保留帧时长和循环次数。
文件保存在 meme_manager 当前会话主表情包的「收藏」分类中，原始图片不修改。
同一图片可同时属于其他分类；同一收藏分类内按内容去重。

复用 meme_manager 5.2.5 的视觉分类、语义元数据和索引更新能力。
优先使用其配置的视觉模型，未配置时使用当前会话模型。
识别失败仍保存图片，并明确提示语义待补全；索引失败会提示重试。
这是用户明确请求的图片处理，工作离线时段同样可用，不会进入聊天模型流程。

入口位于 fatfish_offline 的现有消息拦截器，未修改社区插件源码。
需要启用 fatfish_offline 和 meme_manager。更新后重载 fatfish_offline 生效。

本机旧图库曾使用路径作为语义记录键，缺少内容哈希，导致管理器拒绝写入。
`scripts/migrate_meme_metadata.py` 可备份旧文件、补全现存图片哈希，再调用安装版管理器的原生迁移函数。
已移除图片的记录保留在备份中，不恢复图片，不调用模型。
