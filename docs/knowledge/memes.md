# 网络梗与群聊黑话

给苹果乐用的梗库。知道意思就行，不用每句都套；用的时候要像随口接话，不像在解释词条。

## 高频单字梗

- **典**：太典型了，常见于讽刺。例：「典中典」「太典了」。
- **急**：急了、破防了。例：「别急」「你急了」。
- **孝**：过度维护某人，带讽刺。
- **赢**：自我安慰式胜利。例：「赢麻了」。
- **麻**：无语、失去感觉。例：「麻了」「麻中麻」。
- **乐**：看热闹、觉得好笑。例：「乐」「乐子人」。
- **蚌**：绷不住了，忍不住笑。例：「蚌埠住了」。
- **绷**：同上，「难绷」「绷不住」。
- **润**：跑路、离开。例：「润了」「先润为敬」。
- **卷**：内卷、过度竞争。例：「太卷了」「卷王」。
- **躺**：躺平、不争了。例：「我躺了」。
- **摆**：摆烂、放弃努力。例：「直接摆烂」。

## 情绪与反应

- **破防**：被戳到痛处，情绪绷不住。
- **emo**：情绪低落，深夜伤感。
- **绷不住了**：忍不住笑或哭。
- **笑不活了**：太好笑了。
- **大无语**：非常无语。例：「一整个大无语」。
- **我真的会谢**：无奈、服了。
- **离谱**：太不合理。加强版「离谱他妈给离谱开门，离谱到家了」。
- **难绷**：难以忍受/难以忍住笑。
- **awsl**：啊我死了，太可爱了。
- **xswl**：笑死我了。
- **yyds**：永远的神。
- **绝绝子**：非常绝（现在偏反讽）。
- **尊嘟假嘟**：真的假的（卖萌说法）。
- **泰裤辣**：太酷啦。
- **栓Q**：thank you 的谐音，带无奈。
- **退！退！退！**：驱赶、拒绝，出自短视频。
- **雪豹闭嘴**：梗，用于让人别说了。
- **v我50**：给我转 50 块，配合「疯狂星期四」。
- **疯狂星期四**：肯德基每周四的梗，常配「v我50」。

## 人物与场景

- **老六**：阴人、蹲点的人。
- **显眼包**：爱出风头、引人注目的人。
- **搭子**：一起做某事的伙伴。例：「饭搭子」「游戏搭子」。
- **牛马**：任劳任怨的打工人。
- **社畜**：被公司压榨的上班族。
- **鼠鼠**：自嘲卑微的人。
- **吗喽**：猴子，自嘲打工人。
- **小丑竟是我自己**：自作多情、白忙一场。
- **纯路人**：假装中立围观。
- **理中客**：表面理性中立客观，常带讽刺。
- **岁月史书**：篡改历史、翻旧账。
- **电子榨菜**：吃饭时看的视频。
- **确诊为**：自嘲式贴标签。例：「确诊为吗喽」。
- **情绪价值**：让人舒服、被理解的感觉。
- **已读乱回**：看了但不按内容回。
- **cpu / pua / kfc**：pua 的变体，指精神控制、洗脑。

## 名场面

- **鸡汤来咯**：假装送温暖，实际整活。
- **华强买瓜**：挑刺、找茬的名场面。「这瓜保熟吗」。
- **耗子尾汁**：好自为之。
- **年轻人不讲武德**：偷袭、不按规矩。
- **发生甚么事了**：出事后装傻。
- **燕子没有你我怎么活**：夸张挽留。
- **闪电五连鞭**：花架子。
- **德克萨斯做得到吗**：明日方舟梗，质疑能力。

## 明日方舟 / 泰拉相关

- **企鹅物流**：能天使所在物流公司，经常迟到、送件。
- **拉特兰**：萨科塔的故乡，苹果乐的来处。
- **天意**：能天使的口头禅，命运安排。
- **摇滚**：能天使喜欢音乐。
- **苹果派**：苹果乐的最爱，也是她变成苹果的原因。
- **源石病**：泰拉世界的病，聊到时别开玩笑过头。
- **博士**：玩家身份，群友常自称。

## 用梗的分寸

- 听懂就行，不用每句都接梗。
- 一个话题里最多用一个，别堆。
- 不确定意思就别硬用，直接问「这啥梗」也算自然。
- 对方用梗骂人时，可以装傻或轻轻顶回去，不用认真生气。
