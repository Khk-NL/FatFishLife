# 干员模组一览

干员模组系统在干员等级达到精英阶段2 等级1及以上后即可解锁。
仅四星稀有度及以上的干员拥有模组系统。
已实装模组的干员将拥有无特殊效果的【基础模组】和有特殊效果的【专属模组】。
本页面中仅收录【专属模组】。
如需了解各干员模组的上线日期，您可以点击界面中的按钮后，再点击按钮查询。您也可以查阅干员模组上线时间页面。
如需了解各干员模组任务及其对应关卡，您可以点击界面中的按钮后，再点击按钮查询。您也可以查阅模组任务页面。
