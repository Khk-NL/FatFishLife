# 服务接入与成长记录

本地凭据通过 `scripts/configure_local_services.py --env-file <本机.env> --astrbot <AstrBot目录> --apply` 写入已安装配置；默认不写入。只更新已指定服务，变更前在 AstrBot 的 `data/private-config-backups/` 保存备份，回读核对，终端不输出凭据。Pixiv 始终保留当前已验证配置。

能力使用复用共享记忆的私人 `capability` 事件，涵盖语音表达、语音理解、B站学习、插画检索、资料检索、视频审核、Obsidian、表情语义和游戏价格。记录受限的能力名、阶段和结果，不保存调用参数、凭据、搜索词、音频转写或笔记正文。

- `/生活 成长`：主人私聊查看实际能力经历。生成、送达、认证、学习和投稿各自记录，失败及结果不明也保留；进入私人每日反思，不作为公开动态素材。
- B站学习：沿用 `fatfish_bili` 的标签、时间和数量配置；只有读到评论才记为学到，评论读取失败不消耗去重记录；通知遵守写入预览开关。
- `/知识库 同步`、`/知识库 搜索 <问题>`：原生独立私人知识库，默认北京时间03:00增量同步；源 vault 只读。私有库不要加入群聊的默认知识库或会话库配置。旧 Obsidian 脚本导入器由新插件替代，不再运行旧脚本。
- `/视频 制作 <话题>`：生成本地成片，在主人私聊发送封面、视频和投稿信息；`/视频 确认 <编号>` 只批准这次预览，文件或投稿信息变化需要重新审阅。分区留空时仍可看片，不能投稿。现有画面沿用项目已有模板，角色画面需要另行制作素材。
- `/steam 价格 620`：公开商店查询，不需要 Steam Key，不下载全量游戏目录；可配置现有代理。旧 Steam 插件的目录、监控数据不会被改写。
- `scripts/verify_voice.py`：使用已安装的 TTS/STT provider，在本机完成固定测试语音的合成与转写，输出脱敏报告，不向QQ发消息。
- `fatfish_siliconflow_tts`：原生语音适配器，显式使用参考音色和语速，默认1.1倍；保留原有 Edge 提供商可手动切回。自定义音色 ID 只保存在本机配置，不写入仓库。WAV 流头由已有 FFmpeg 规整后才交给平台。
- `scripts/generate_meme_semantics.py`：复用已安装 meme_manager 原生视觉描述及索引逻辑，断点续跑，保留人工分类。详见 [表情语义说明](meme-caption-prompt.md)。

语音、知识库和视频产物涉及主观效果或实际账号行为；接口和本机测试不替代听感、平台实际送达与最终投稿审批。配置模板使用安全初始值，部署到其他机器时必须填入该机器的主人、模型、vault和分区配置。
