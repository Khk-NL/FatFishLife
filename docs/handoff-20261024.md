## A 类：只能用户本人在 QQ 里做

### A1. 清会话（最急）

在 QQ 私聊 bot 发送：

```
/reset
```

群里发送时要指定目标：`/reset 群:群号`。

**为什么**：`emotionai` 插件此前每轮注入一条假用户消息「（系统自检：请报告当前情感状态）」，导致 bot 反复输出「我是苹果乐，不写什么星绘报告」。注入源头已改，但历史里还留着污染对话。

**验证**：发完之后随便聊两句，不应再出现"自检""星绘""报告"字样。

### A2. 重建知识库

```
/设定 导入
```

**为什么**：本轮更新了 `docs/knowledge/` 下几十个文件（活动梗概 153 个、能天使家庭、众生行记、网络梗库、PRTS 剧情与地理），知识库仍是旧的 64 块。

**验证**：问「众生行记是什么活动」，回答应提到新约能天使登场。

## B 类：接手的 agent 可以做

### B1. 建表情语义索引

**背景**：163 张表情包的画面描述已经生成（用 `deepseek-flash` 逐张看图写的，质量可用），但手动写入 `semantic_metadata.json` 失败 —— `meme_manager` 用的 key 是 `semantic_entry_id(内容sha256 + 分类 + 相对路径)`，脚本写入后插件重新扫描时算出的 key 完全对不上（164 条全不匹配），插件因此判定"描述未完成"，拒绝建索引。

**已完成**：`scripts/gen_meme_captions.py` 可以生成描述，逻辑正确，只是写不进插件认可的格式。

**要做**：在 WebUI → 表情包 → 语义化页面点击「开始」，让插件自己扫描 + 调视觉模型 + 建索引。

**验证**：`D:\Code\Apps\AstrBot\data\plugin_data\meme_manager\semantic_indexes` 目录应有新索引文件；日志不再出现「图片描述尚未全部完成」。

### B2. 群禁言功能

**需求**：指定群完全静默 —— 不回应 @、不接关键词、不随机插话、不延续对话。

**做法**：在 `bots/astrbot_plugin_fatfish_offline/` 加配置项 `mute_groups`（群号列表，字符串数组），命中后在 `on_waiting_for_reply` 阶段直接 `stop_event`。

**待用户确认**：该群里的命令（`/jms`、`/搜索`、`/记忆`）要不要一并禁用。

**验证**：在静音群里 @ bot，应无任何回复；非静音群行为不变。

### B3. 补齐剩余 72 个活动梗概

**背景**：153 个活动里 81 个有真实内容，72 个标「资料不足」——PRTS 页面只有活动公告、没有剧情文本。

**已有工具**：`scripts/rewrite_activity_summaries.py`（单页重写）、`scripts/retry_lack_summaries.py`（换页面名重试）。已试过加年份后缀，只救回 7 个。

**可选方向**：手写补全，或从 B 站活动介绍视频抓字幕（`bili.exe video watch <BV号>`）。

**注意**：不要回到"让模型自由发挥"的做法。已经验证过，模型对 2026 新活动会硬编——恒远津梁实际是国家图书馆联动签到，模型编成"岁家过年剧情"。
