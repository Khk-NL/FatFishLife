# 功能审查与复用清单（更新至 2026-10-25）

审查依据：当前 AstrBot 4.29.1 源码、已安装社区插件、FatFishLife 调用链与配置、针对性测试，以及明确标注的真实服务回执。安装成功、测试替身通过、已经生成方案都不等于真实账号端到端验收。

## 已发现并处理的问题

- 截图时段核对到 10 次调用属于同一原生会话、没有时间重叠；原生已有完整 UMO 会话锁，因此不把现象简单归因为并发串群。按标点分段、原生多步消息输出及默认引用会放大碎片与重复引用：改为关闭分段/默认引用，复用原生中间消息缓冲，再整理最终纯文本。
- 原生会先执行硬轮数裁剪再做 token 摘要。取消 12 轮硬裁剪，保留 12000-token 预算和 MiniCPM 摘要，让初始查询目标有机会被总结，而非先丢掉。
- `_pending_trigger` 原用群共享槽位，队列中的不同事件可能覆盖回复对象；现绑定到入站事件，沿用原生串行处理。
- 明确的方舟前瞻问题通过本轮已获权限的 AnySearch 工具做一次只读检索；同会话后续抱怨/追问继承原问题，成功依据短期缓存，不追加模型自检或新 Agent。工具回执与模型口头承诺分开，不能把无依据文本当已执行。
- 配置文件由 AstrBot 写入 UTF-8 BOM 后，共享数据库路径读取曾导致 memory/offline 等插件加载失败；已改 `utf-8-sig` 并增加真实 BOM 配置回归测试。
- QQ 默认命令及帮助统一英文，复用原生 alias 保留中文兼容；修复 GreedyStr 默认值导致多词正文被截断的问题，见 `docs/COMMANDS.md`。
- 工作时间的离线命令白名单漏了 `/生活`、`/视频`、`/cost` 等现有命令，主号也会被吞。改为复用原生已做权限检查的注册命令路由。授权列表本来已正确，不通过给所有人管理员来解决。
- `/reset` 指定目标用平台类型代替适配器 ID，现使用原生适配器 ID 构造完整会话标识。
- B站学习原来用 CLI 默认 9 帧和自动字幕/音频转写；现复用已有 `--frames 0 --transcript subtitle` 模式，字幕缺失就只读标题、标签、简介和评论，不回退音频处理。
- 聊天记忆原来直接存 message_str，复读没有压缩。现只取 Plain 正文，清理协议 @、图片/合并消息等占位；纯占位跳过，连续复读显示为“话 × n”，不计作多份学习证据。
- 共享聊天不再存发送人，旧聊天记录提供事务迁移；导出的 Markdown 按平台、完整会话和公私范围独立保存，不加入全局公开知识库。
- 上轮新增的 context 插件与 memory 职责重叠，现合并到 memory，保留同一媒体整理逻辑、`/cost` 和原报告位置，自建插件从 11 减为 10。
- `.env` 同步原先只更新旧 Obsidian 插件配置，无法更新正在使用的私人 vault；现更新当前 native KB 适配的 vault_path，并保持旧导入器不自动运行。
- README 仍把旧模板视频作为主入口，现明确当前机器人只走 Updream；历史工具保留兼容，不再推荐为机器人制作链。

## 本轮审查边界

已逐项核对上述职责、关键入口和依赖。真实发言、投稿、QQ空间公开发布、付费音色克隆仍按原授权和验收条件执行，没有用模拟结果替代。

代码审查 CLI 尝试了有预算上限的检查；工具预计单组输入超过上限并停止，返回失败，不能把“0评论”当作无问题。结论依据源码核查、隔离测试及列出的真实服务回执，不以该失败结果背书。

后续执行 `AGENTS.md`：新增功能先核对原生能力和已装/社区插件；已覆盖的直接复用，必要时只补薄适配。借鉴代码先核对接口和许可证，不无条件安装整套新依赖。当前核对的[原生知识库文档](https://github.com/astrbotdevs/astrbot/wiki/en-use-knowledge-base)明确无需额外知识库插件。

## 截图问题的验收范围

完整文本日志未保留，当前历史也经过裁剪，不能从“剩余历史没有 tool_calls”断言所有早期请求都未执行过工具。原生回放使用明确的 synthetic NoSendEvent，真实调用只读搜索与模型，禁止发送 QQ 消息；它验证查询、追问目标与格式，不冒充真实主账号入站验收。

首轮真实回放暴露了省略旧公告年份的问题。已把北京时间日期、搜索年份和“旧年份不可当本场结论”的约束放入本轮动态检索依据，要求引用事实带原始URL。最终三轮原生回放只搜索一次，追问保留原目标，亲昵闲聊不搜索。模型偶发漏贴链接由响应收尾附上真实检索URL，不新增模型调用；相关32项测试通过。完整暂存区快照500项测试复跑通过。

人设保留中文：温暖、有主见、爱玩、轻微嘴硬，对老大的亲昵称呼自然接话。闲聊短，查询保留完整结论与来源；日常句尾少用句号，查询依据不足就明确范围，不靠反复“我去查”维持对话。
