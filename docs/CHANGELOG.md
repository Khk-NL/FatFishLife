# 变更记录

## 2026-10-23：QQ 戳一戳与 @ 区分

- 修复在线模式提前返回导致头像双击事件不触发的问题，优先解析原始 `notify/poke` 与 `Poke` 组件目标，只处理戳到机器人本人的事件。
- 在线戳一戳使用独立 `poke` 触发；普通 @ 使用 `mention`，空 @ 本地简短回应，@ 加文字或图片继续原流程。
- 保留现有未提交的空 @ 回应及 `target_id()` 兼容处理，离线与模型额度耗尽时使用本地戳一戳台词。

验证：新增 10 项事件回归覆盖群聊/私聊、在线/离线、其他目标、空 @ 和 @ 附件。未向真实 QQ 发送测试消息，头像双击的实际收发待验收。

## 2026-10-23：共享记忆进入普通对话

- QQ 在模型请求前检索相关记忆；B 站自动回复复用同一个上下文构建器。
- 原始聊天按平台、会话隔离；明确保存的笔记在权限范围内跨平台共享。公开评论只读取公开层，主人私信可读取私人笔记和札记。
- 中文检索最多读取 40 条有效候选、选取 6 条，默认总量不超过 1800 字符。旧收件箱和无会话标记的私信快照不进入自动上下文。
- B 站仅在实际发送成功后记录来信及回复，预览不形成已发送对话。

验证：33 项记忆测试、13 项 B 站插件测试通过；现有运行接入检查确认五个插件已加载、OneBot 有连接记录、B 站登录有效。未发送测试消息或重启运行中的 bot。

## 2026-10-22：双 bot 私人记忆隔离

- 私人记忆、总结和成长札记仅在主人的私聊中读取；主人在群聊中也只能检索公开记忆。札记提炼同样限定主人私聊。
- 所有私聊消息保存为私人记录。B 站收件箱包含私信和系统通知，整份快照保存到私人层。
- B 站账号状态、登录、确认、收件箱、立即处理消息和发送私信限定主人或 AstrBot 管理员私聊；收件箱 LLM 工具遵守同样规则。QQ 主人身份同时检查平台。
- B 站后台通知保留公开评论回复，私信仅报告已处理，不转发正文或回复内容。
- 共享记忆插件加载时，把旧版错误归入公开层的 B 站收件箱快照改回私人层；B 站记忆查询也阻止这些旧快照被公开访问。其他历史消息无法可靠判断私聊来源，保持原分类。

验证：`python -B -m unittest discover -s tests -v`，50 项测试通过，包含真实本地媒体编码与模拟 bot 权限测试。未进行真实 QQ/B 站收发，也未重载运行中的插件；更新生效需重载两套插件。
