# 变更记录

## 2026-10-23：自主生活日记与双平台动态

- 新增 `astrbot_plugin_fatfish_life`：默认北京时间 23:50 写私人日记，再单独依据最近 3 天的公开经历生成最多 160 字的动态。公开请求不读取私聊、私人日记或会话身份。
- 基础概率从 20% 开始，未成功发布次日增加 20 个百分点，最高 100%；任一平台确认成功后回到 20%。模型可选择当天不分享，也可把当天概率上下调整最多 20 个百分点。
- 中签后默认 45% B 站、45% QQ 空间、10% 双平台；模型可根据公开互动和自己的分享意愿调整权重，并保留理由和近期选择。没有可公开的事实时不凑文案。
- 发布前持久保存决定，两个平台分别记回执。超时、缺回执或中断后暂停对应平台，不自动重发；仅确认成功的发布会重置概率。QQ 空间核验并锁定授权机器人账号，不使用主人大号。
- `/生活`、`/生活 日记`、`/生活 草稿` 等只允许主人或管理员私聊查看。插件默认只留草稿；本机已按本次自动发布请求开启发布并配置机器人账号，保存后热重载。

验证：当前全套 310 项测试通过，其中生活模块 78 项。另用临时记忆和模拟经历进行了两次真实 DeepSeek 调用，结构化日记和公开草稿均返回，公开请求不含私聊测试标记，未调用任何发布接口。已在真实控制台核对 23:50、自动发布开启和机器人账号；真实平台首条动态仍待验收。

验证：新增 19 项纯调度测试和 9 项模拟发送集成测试；全套 203 项测试通过，覆盖概率与时刻边界、持久去重、跨日、时区、失败及取消。全部使用临时状态和模拟发送，未向真实 QQ 发消息；实际接收群由本人在控制台填写后验证。

## 2026-10-23：B 站自动回复暂停与恢复

- 修复“通知已暂停、下一轮仍访问 B 站”的问题。自动读取 @、评论和私信，或自动发送评论、私信时，遇到未登录、登录过期、风控或验证码错误后立即停止当前轮，保存本进程的暂停原因，只通知一次。
- 暂停后的轮询、强制处理和自动回复入口不再调用 CLI 或模型；已经生成的回复也会在发送前再次检查暂停状态。普通手动命令和已有预览去重规则保持不变。
- 状态命令显示暂停原因。主人或管理员私聊中的 `/bili 恢复` 先核实登录，成功后解除暂停，不立即拉取或发送；失败保留暂停，单独确认登录不会自动恢复。暂停不跨进程持久化。

验证：AstrBot Python 3.12 中 29 项 B 站插件测试全部通过，新增 11 项暂停与恢复回归，覆盖四类错误、读取与发送入口、后续轮询阻断、恢复权限与失败保留，以及网络错误不会误触发暂停。测试只使用模拟 CLI、模型和通知，未进行真实 B 站收发或修改生产配置。

## 2026-10-22：双 bot 私人记忆隔离

- 私人记忆、总结和成长札记仅在主人的私聊中读取；主人在群聊中也只能检索公开记忆。札记提炼同样限定主人私聊。
- 所有私聊消息保存为私人记录。B 站收件箱包含私信和系统通知，整份快照保存到私人层。
- B 站账号状态、登录、确认、收件箱、立即处理消息和发送私信限定主人或 AstrBot 管理员私聊；收件箱 LLM 工具遵守同样规则。QQ 主人身份同时检查平台。
- B 站后台通知保留公开评论回复，私信仅报告已处理，不转发正文或回复内容。
- 共享记忆插件加载时，把旧版错误归入公开层的 B 站收件箱快照改回私人层；B 站记忆查询也阻止这些旧快照被公开访问。其他历史消息无法可靠判断私聊来源，保持原分类。
