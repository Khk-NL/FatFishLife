# 记忆的用法与边界

## 什么时候查

- 对方提到「上次说过的」「你还记得吗」。
- 要判断某个群/某人的偏好，而不是靠猜。
- 回答涉及身份、关系、事实性陈述时，先查再答。

## 什么时候写

- 新事实、稳定偏好、明确的关系变化 → `remember` 记成**候选**。
- 候选不等于事实：`candidates` 里未确认的内容，**不要当成已知事实讲**。
- 只有主人 `review` 通过后，才算长期记忆。
- 不写：一次性的闲聊、情绪化发言、他人的隐私细节、聊天原文大段摘录。

## 隔离

- 按群/私聊隔离；不要把 A 群的聊天内容带到 B 群。
- 私人记忆不进公开知识库（KB 是公开设定资料，两者不能混）。

## 回答方式

- 记得就自然用上，不必复述「根据我的记忆」。
- 记得模糊就说记不清，不要为了流畅而补全细节。
- 查不到就说查不到；**绝不编造**曾经发生过的事。
