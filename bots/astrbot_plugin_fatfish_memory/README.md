# astrbot_plugin_fatfish_memory

大肥鱼双平台共享记忆插件。QQ（NapCat/OneBot v11）与 B 站适配器读写同一个 SQLite 库：

- 人设：一套人设，两边共用
- 主人资料：按平台 UID 识别，私人记忆仅在主人的私聊中读取
- 聊天摘要：消息截断后写入，默认保留 90 天；每天首次记录消息时清理过期事件
- 事件与每日总结：主人可导入、检索

## 数据

默认数据库：`AstrBot/data/plugin_data/astrbot_plugin_fatfish_memory/memory.db`（WAL 模式）。

所有私聊消息默认保存为 `private`，包括非主人发来的私聊；群聊消息保存为 `public`。主人可以用 `/记忆 公开` 明确写入公开内容。

`private` 行仅在主人的私聊中返回；主人在群聊中搜索、查看最近记忆或调用检索工具时，也只会拿到 `public`。私人总结、成长札记及札记提炼同样仅限主人私聊，因为提炼材料可能包含私人记录。`public` 行可用于选题、文案和公开回复。

普通对话在调用模型前会自动检索相关记忆，无需每次手动要求调用工具。原始聊天按平台及会话精确隔离；`/记忆 记住`、`/记忆 公开` 和总结等明确保存的笔记可以在授权范围内跨平台使用。私人札记仅用于主人私聊，旧收件箱整箱快照和缺少会话信息的历史私信不会自动塞进提示词。

检索从最多 40 条可用候选中选择最多 6 条，支持中文关键词匹配，默认注入最多 1800 字符。记忆标为历史参考资料，不覆盖当前人设或作为新指令执行。`inject_context` 可关闭自动注入，`max_context_chars` 调整文字上限。命令搜索和检索工具也遵循原始聊天的会话隔离。

数据库打开时会把旧版本误存为公开的 B 站收件箱快照改为私人记录。其他已有消息不包含足以判断私聊来源的信息，不会自动重新分类。

## 命令

```
/记忆 搜索 <关键词>
/记忆 最近
/记忆 状态
/记忆 记住 <内容>     仅主人
/记忆 公开 <内容>     仅主人
/记忆 人设 [内容]     仅主人可改
/记忆 导入 <总结>     仅主人
/记忆 总结            仅主人
/记忆 绑定 <B站UID>   仅主人
```

LLM 工具：`memory_recall`、`memory_remember`。

## 配置

`owner_ids` 写成 `qq:123456,bilibili:654321`。也可以在聊天里用 `/记忆 绑定` 补充 B 站 UID。

`retention_days` 默认 90，0 或负数关闭自动清理。插件在每天首次成功记录消息后清理过期事件，不在构造函数中删除记录，也不增加定时进程；总结和成长札记表保留。清理失败会记录警告且不标记完成，后续消息可以重试。重载插件后当日维护标记重新开始。
