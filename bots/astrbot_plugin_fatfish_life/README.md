# 苹果乐的每日生活

每天默认在北京时间 **23:50** 写私人日记，再自己决定要不要分享最近的经历。时间可在控制台的 `reflection_time` 修改，保存后重载插件生效。

私人日记可以回顾当天已记录的公开聊天和私聊，仅老板私聊可查。公开动态会另起一次生成，只读取最近 **3 天**的公开经历，不读取私人日记和私聊；`lookback_days` 可设为 1～7 天。它会区分自己实际做过的事、别人的行动和仅发现的候选素材，没有事实就不编故事。

公开文案最多 **160 字**，以苹果乐的人设随手讲讲做了什么、别人如何回应、自己有什么感想。模型需要提供对应的事实编号，文案不带账号、链接或 @，并要求避免人名、昵称、群名和他人原话。

## 自己决定是否分享

- 首日基础概率为 20%；没有成功发布，次日增加 20 个百分点，最高 100%。任一平台确认发布成功后，下一天回到 20%。
- 模型可以明确表示今天不想分享，也可以结合已记录的使用量、充实程度和兴趣，把**当天**的概率上下调整最多 20 个百分点；调整不会永久叠加到基础概率。
- 中签后，默认 45% 只发 B 站、45% 只发 QQ 空间、10% 两边都发。模型可以根据公开互动和自己的意愿调整这三项权重，决定和理由会保留在当天记录里。
- 已暂停的平台不会被模型自行恢复；没有可公开的经历时只写日记，不为了达到概率而凑一条动态。

使用量来自 AstrBot 的 `provider_stats` 实际记录。生活插件自己的模型调用也会在响应带有用量时写入该表。已有 B 站、Qwen 等直接调用可能尚未入账，因此这里是**已记录的 token 用量**，不是完整计费统计；统计不可用时也不会当成用量为零。

## 接入和发布开关

将本目录接入 `AstrBot/data/plugins/astrbot_plugin_fatfish_life`，本地可沿用项目已有的目录链接（junction）方式，再重载插件。需要启用共享记忆插件，并配置好 AstrBot 的默认模型。

控制台配置：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | `true` | 每天写日记并作出分享决定 |
| `reflection_time` | `23:50` | 北京时间，格式 `HH:MM` |
| `publish_enabled` | `false` | 关闭时仅留草稿，打开才允许自动发布 |
| `lookback_days` | `3` | 公开回顾范围，1～7 天 |
| `qq_platform_id` | `napcat` | QQ OneBot 连接 ID |
| `qq_bot_id` | 空 | 发说说的机器人，当前只允许填 `1670515707` |
| `persona` | 空 | 留空使用项目苹果乐人设，必要时沿用 B 站插件人设 |

发布 B 站动态还需要启用 B 站插件、完成登录，并把该插件的 `dry_run_writes` 设为 `false`。只打开生活插件的发布开关，B 站仍处于预览模式时不会真发。

QQ 空间只允许机器人 **1670515707** 发布。每次先校验登录账号，核验和发布都锁定该账号；账号不符、连接不可用或未填账号时不发送，不使用老板大号。发布的是纯文字说说。

修改配置后重载插件。服务需要保持运行；晚于当天总结时间启动时会处理当天，不逐天补发停机期间的动态。

## 老板私聊命令

| 命令 | 用途 |
| --- | --- |
| `/生活` 或 `/生活 状态` | 查看当天决定、模型理由、概率、发布记录和暂停状态 |
| `/生活 日记` | 查看今天的私人日记 |
| `/生活 成长` | 查看今天真实使用的能力、阶段和成功/失败/待核验次数 |
| `/生活 草稿` | 查看今天的公开草稿 |
| `/生活 预览` | 立即完成今天的总结和抽签，本命令不发布 |
| `/生活 恢复 bilibili` | 人工核验后解除 B 站的生活动态暂停 |
| `/生活 恢复 qzone` | 人工核验后解除 QQ 空间的生活动态暂停 |

**预览会用掉当天的决定。** 无论仅留草稿还是手动预览，当天处理完就不会因随后打开发布开关、重载插件或再次执行命令而补发；新的分享从下一天开始。

发布前会先保存记录，双平台分别留回执。超时、缺少有效回执或发布中断会标记为 `uncertain` 并暂停对应平台，不自动重试。先到平台核验是否已发出、处理登录或风控，再使用恢复命令；恢复也不会重发今天已经处理过的文案。

目前验证覆盖本地状态、数据隔离和模拟发布；真实账号的动态发布仍待验收，模拟成功不代表已经在平台发出。

## 能力经历与成长

语音表达、语音理解、B站标签学习、Pixiv、AnySearch、视频创作与审核、独立 Obsidian 知识库、表情语义和 Steam 查询共用共享记忆中的私人 `capability` 事件。每天反思会单独读取这些事件，回顾成功、失败和仍待核验的尝试，形成下次想学或想改进的内容。这里按实际阶段记录，不把保存配置、通过认证、生成文件当成已发送、已同步或已投稿。

生活插件监听已完成的 Pixiv/AnySearch/B站文字读取/表情搜索工具回执；空回执留为待核验，明确报错记为失败。QQ 语音在发送完成后记下 `tts/delivery`；OneBot 原始语音经过 AstrBot 转写、被文本替换后记下 `stt/transcribe`。没有对应事实时不会推断成功；命令模式、后台学习、第三方语音失败等没有标准回执钩子的路径，需由实际调用方记录结果：

```python
from fatfish_core.growth import record_capability

record_capability(memory_store, "bili_learning", "success", stage="learn")
record_capability(memory_store, "video_review", "blocked", stage="publish", error_code="awaiting_review")
```

能力名、状态、阶段和错误码均使用固定白名单。接口不接收搜索词、转写文本、错误消息、Token、账户、文件路径或回执原文；记录只进入私人日记和老板私聊的 `/生活 成长`，不会进入公开动态素材。视频仍需老板看片并确认才允许投稿，成长记录不替代这项确认。
