# 群聊语气学习

复用 Self Learning 的 `filtered_messages` 与风格候选，不重复采集聊天，也不改写原插件的候选审核和人设数据。只分析当前群的真人消息；原来的 `default/apple-le` 重复表达按内容去重。

配置 `bot_id` 后，在QQ群的模型回复前后台检查新语料，至少10条时提炼最多6条适合苹果乐的表达习惯。每条要求两条真人语料证据和足够置信度；默认每群每小时最多一轮。模型失败不消耗语料进度。人设核心、身份与事实不会被群友样本覆盖。

样本和反馈按机器人、群分别存储在共享SQLite的 `runtime_state/group_style` 中，不写入可跨群召回的公开记忆。回复只带一条习惯或最多两条相关示例，45秒冷却，只有消息成功发送才统计“参考”。参考次数不代表模型一定逐字采用，也不代表效果已得到认可。

- 群里 `/语气 状态`、`/语气 样本`：查看本群吸收进度与表达示例。
- 收到回复后10分钟内 `/语气 喜欢` 或 `/语气 不喜欢`：由当次对话者评价最近参考；不喜欢的样本停用，喜欢的适当提高权重。
- 自然反馈也支持精确短语“这个语气很好”“就这样说”“别这么说了”“别学这个”。不会把普通笑声或无关群消息推断成反馈。
- 老板可在群里 `/语气 学习`，或私聊 `/语气 状态 <群号>`、`/语气 样本 <群号>`。

学习结果进入 `/生活 成长` 的“群聊表达学习”与私人每日反思，统计与原始语气样本分开。原生 Self Learning 的全量上下文注入可继续关闭，避免把关系、心理状态、旧记忆和口吻一起混入；本插件只注入同群表达参考。
