# 苹果乐表情包

收藏、审核、随机发送苹果乐 / 能天使表情包。

## 命令

```
/表情                随机一张
/表情 苹果乐         按关键词找
/表情 收藏 [标签]    把当前图片收进库（主人直接入库，其他人待审）
/表情 待审           主人查看待审核
/表情 通过 <id> [标签]
/表情 拒绝 <id>
/表情 列表 [关键词]
```

## 说明

- 图片存在 `data/plugin_data/astrbot_plugin_fatfish_stickers/images/`，索引是同目录的 `library.json`。
- 主人（`owner_qq` 或 AstrBot 管理员）收藏的图片直接可发；其他人的投稿进待审。
- 标签支持逗号分隔，例如 `/表情 收藏 苹果乐,能天使,开心`。
- 想批量导入自己下载的图，把文件放进 `images/` 再手工写 `library.json` 比较麻烦，后续会补一个导入脚本。
