# Updream 视频制作与主人审阅

机器人视频统一使用 Updream。`/视频 制作` 准备叙事方案，不调用原来的模板贴脸渲染器，也不会退回旧模板生成视频。

1. `/视频 选题` 查看公开候选。
2. `/视频 制作 <话题>` 生成完整创作方案：人物动机、冲突、镜头行动、角色一致性、对白与声音设计。方案只取公开话题和公开图谱，保存到插件数据目录 `updream/<编号>/creative-brief.md`。
3. 在已登录的 Updream 中按方案制作与导出。尚未核实官方公开 API；当前通过官方网页操作，平台条款、实际积分与生成效果需要验收，不把本地方案冒充平台成片。
4. 主人私聊 `/视频 导入 <本机成片路径>`，核验完整解码、提取封面，保存专用审阅副本，再私聊发回成片。导入来源由主人声明，媒体检查不会声称证明了平台来源。
5. `/视频 确认 <12位审阅编号>` 仅投稿对应预览；`/视频 取消 <编号>` 取消本地审批。

控制台需配置 `owner_qq`、标签、`zone` 和 `tid`。B站复用 `fatfish_bili` 的登录环境。分区缺失时可以看片，投稿会被阻止。

只允许主人 QQ 私聊操作，管理员身份不能替代主人确认。预览发送全部成功才允许批准；视频、封面、媒体报告和投稿信息绑定文件摘要，修改后必须重新预览。提交中断或回执不明时停止自动重投。

方案准备、导出核验、预览与投稿分别记录成长结果；模型不能批准投稿。Updream 操作细节见 [接入说明](../../docs/UPDREAM.md)。
