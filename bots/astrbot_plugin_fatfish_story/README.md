# 视频制作与主人审阅

依赖本项目已安装的 `fatfish_story`、`fatfish_video`、`fatfish_bili` 和本机 FFmpeg；AstrBot 与 NapCat 需能访问同一成片路径。生成使用 AstrBot 当前会话选中的模型，空对话上下文，不读取私聊或私人日记。

在控制台配置主人 QQ，或留空沿用 `fatfish_bili.owner_qq`。填入明确的投稿标签、`zone` 和 `tid`。分区未配置仍可制作看片，但确认投稿会被阻止。B 站执行环境沿用已启用的 `fatfish_bili` 插件登录环境。只允许该 QQ 主人在私聊操作，管理员身份不能代替主人批准。

1. `/视频 选题` 查看最近公开发现的候选；也可以直接给出话题。
2. `/视频 制作 <话题>` 生成分镜、渲染 MP4，再把成片和标题、简介、标签、分区发到当前主人私聊。
3. 看过成片后，主人发送 `/视频 确认 <12位审阅编号>`，才调用既有投稿适配器提交审核。没有任何模型工具或每日任务能够批准投稿。
4. `/视频 状态 <编号>` 查看本地回执；`/视频 取消 <编号>` 取消本地审批。

`/视频 预览 <编号>` 重发预览。控制台投稿信息发生改变时，它会分配新的审阅编号，旧编号失效，需要对新的信息再次看片确认。视频、封面、渲染报告与投稿信息都绑定 SHA256；修改产物会阻止提交。

审阅记录与成片分别保存在插件数据目录的 `reviews/`、`videos/`。投稿前先持久保存 `submitting`；超时、异常或中断后保留不可自动重试的状态，须先到 B 站稿件列表确认远端状态。`submitted` 仅表示提交审核。生成、预览发送和投稿的结果通过 `fatfish_core.growth.record_capability` 记入 `video_review` 能力成长记录，不把视频正文、私聊或凭据复制到成长摘要。

本地模拟测试覆盖权限、预览绑定、修改后重新审批与异常不重投。真实 QQ 视频送达、账号分区与 B 站上传审核仍需账号环境验收；自动测试不会发送消息或投稿。画面仍沿用项目现有模板和角色素材，正式投稿前由主人检查画面、音乐和字幕。
